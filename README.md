# CKA Study Tracker

2027년 1월 30일 CKA 취득을 목표로 하는 직장인을 위한 로컬 우선 학습 관리 대시보드입니다. 14주 계획, 실제 학습 세션, 진도율, 캘린더, 타이머와 통계를 한 화면 흐름으로 관리합니다.

## 실행 방법

Node.js 20.9 이상과 pnpm이 필요합니다. pnpm이 없다면 먼저 `corepack enable`을 실행하세요.

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

검증 명령:

```bash
pnpm typecheck
pnpm test
pnpm build
```

## 기술 스택

- Next.js 16 App Router, React 19, TypeScript strict mode
- Tailwind CSS 4, Zustand 5, Recharts 3, Lucide React
- 브라우저 localStorage 기반 영속화, 스키마 버전 `v1`
- Vitest 단위 테스트

## 프로젝트 구조

```text
src/
├── app/                    # App Router 페이지 및 전역 스타일
├── components/
│   ├── calendar/           # 월간 캘린더와 히트맵
│   ├── charts/             # Recharts 통계 화면
│   ├── dashboard/          # 대시보드
│   ├── layout/             # 반응형 앱 셸
│   ├── study/              # 계획, 항목 폼, 설정
│   ├── timer/              # 복원 가능한 학습 타이머
│   └── ui/                 # 공통 UI
├── data/                   # 14주 CKA 기본 로드맵
├── features/statistics/    # 순수 집계/계산 로직
├── lib/                    # 날짜, 타이머, 저장소, 포맷 유틸리티
├── stores/                 # Zustand 애플리케이션 스토어
└── types/                  # 도메인 타입
```

## 구현된 기능

- D-Day, 오늘/주간/전체 학습량, 시간 진도율, 항목 완료율, Streak, 다음 학습 대시보드
- 2026-10-26부터 시작하는 구체적인 CKA 14주 기본 계획 83개 자동 생성
- 월간 계획/실제 시간 캘린더와 GitHub 스타일 14주 히트맵
- 학습 항목 생성·수정·삭제·완료·날짜 이동, 과거 수동 시간 기록
- 시작·일시정지·재개·종료, 새로고침/브라우저 재실행 복원, 중복 실행 방지 타이머
- 한국 시간 자정을 넘기는 타이머 세션의 날짜별 분할 집계
- 요일별 계획/실제, 목표 달성률, 영역별 분포, 14주 누적 추이 통계
- 다크/라이트 테마와 데스크톱·태블릿·모바일 반응형 UI
- 설정 가능한 시작일, 시험일, 주간·전체 목표, Streak 휴식 요일
- 유효성 검사를 포함한 JSON 내보내기/가져오기, 확인 절차가 있는 전체 초기화

## 계산 정책

- 오늘/주간 학습 시간은 저장된 실제 세션의 합입니다.
- 시간 진도율과 항목 완료율은 별도 지표로 계산합니다.
- 달성률 수치는 100%를 초과할 수 있지만 Progress Bar 너비는 100%로 제한합니다.
- 실제 학습 기록이 있는 날짜만 Streak에 더합니다. 설정한 휴식일은 기록이 없어도 Streak를 끊지 않지만 일수에는 더하지 않습니다.
- 오늘 학습 전에는 전날까지의 Streak를 유지합니다.

## 알려진 제한사항

- 데이터는 현재 브라우저 프로필의 localStorage에만 존재하므로 다른 기기와 자동 동기화되지 않습니다.
- 백그라운드 탭의 화면 표시는 브라우저 정책에 따라 늦게 갱신될 수 있으나, 타이머 결과는 시작 시각 기반으로 정확히 복원됩니다.
- 설정에서 시작일이나 시험일을 바꿔도 이미 생성된 개별 학습 항목 날짜는 자동 재배치하지 않습니다. 계획 화면에서 항목별로 이동할 수 있습니다.
- 마지막 14주차는 시험일이 토요일이므로 기본 일요일 복습 항목을 만들지 않습니다. 전체 목표 161시간은 독립적으로 유지됩니다.
